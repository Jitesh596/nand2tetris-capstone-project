# Part A — Build the Hack computer

Copy your own completed lab implementations into this folder:

- `CPU.hdl`
- `Memory.hdl`
- `Computer.hdl`

Do not submit empty or placeholder HDL chips. Run the official tests from the assignment:

- `CPU.tst`
- `Memory.tst`
- `ComputerAdd.tst`
- `ComputerMax.tst`
- `ComputerRect.tst`

Save a screenshot of each successful test. If you use a built-in chip because one of your
lab chips does not work, mention that in your report as the assignment requires.
