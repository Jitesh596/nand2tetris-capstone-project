# Nand2Tetris Capstone - Project Files

This folder follows the teacher's requested submission layout: put the source and output files directly inside **Project Files**.

## Included now

- `assembler.py` - a two-pass Hack assembler (A-instructions, C-instructions, predefined symbols, labels, and variables).
- `project_config.py` - set `K` to the last two digits of your own roll number. It is intentionally `None` until you set your own value.
- `Assembler_SmokeTest.asm` and `Assembler_SmokeTest.hack` - a small assembler smoke test and the machine-code output generated by this assembler. It computes `RAM[2] = RAM[0] + RAM[1]`.
- `.vscode/extensions.json` - recommends Microsoft's Python extension in VS Code.

## Run the included assembler test in VS Code

Open the `Project Files` folder in VS Code. Open Terminal > New Terminal and run:

```powershell
py assembler.py Assembler_SmokeTest.asm Assembler_SmokeTest.hack
```

If `py` is unavailable, try `python` instead. Python 3 must be installed separately from the VS Code extension.

## Before submitting

1. Set `K` in `project_config.py` to your real last two roll-number digits.
2. Add your own completed `CPU.hdl`, `Memory.hdl`, and `Computer.hdl` files. Test them using all five official test scripts listed in the assignment and keep the actual screenshots for your report. The `Pending-Part-A-HDL` folder is currently empty.
3. Test `assembler.py` against the official `Add.asm`, `Max.asm`, `Rect.asm`, and `Pong.asm` files. Compare the generated `.hack` output with the official assembler. The included smoke test is not a substitute for those four required tests.
4. Write `Box.asm` for your actual K value, assemble it using this Python assembler to produce `Box.hack`, then run it in the official CPU Emulator. The `Pending-Part-C-Box` folder is currently empty.
5. Complete the report template in the parent folder with your own name, roll number, box dimensions, real test screenshots, final box screenshot, and a paragraph about a mistake you fixed.

## K-based extra assembler feature

The assembler selects the assignment's required extra feature using `K % 3`:

- `0`: writes labels and variables to `symbols.txt`.
- `1`: reports invalid instructions with their source line numbers.
- `2`: warns about duplicate labels.

Do not submit this ZIP unchanged as a completed assignment. The two pending folders and the report template must be completed using your own lab work and actual test evidence.
