# Part A — Hack computer HDL files

This folder contains the three HDL source files required by the capstone:

- `CPU.hdl`
- `Memory.hdl`
- `Computer.hdl`

## Before testing

1. Open these files with the official Nand2Tetris Hardware Simulator.
2. Make sure the standard chip dependencies from your course/lab workspace are available (for example `ALU.hdl`, `ARegister.hdl`, `DRegister.hdl`, `PC.hdl`, `RAM16K.hdl`, `Screen.hdl`, `Keyboard.hdl`, and the required gate/mux chips), or use the simulator's built-in chips where permitted by the assignment.
3. Run the official test scripts: `CPU.tst`, `Memory.tst`, `ComputerAdd.tst`, `ComputerMax.tst`, and `ComputerRect.tst`.
4. Save genuine screenshots of each passing test for your report.

These files are source implementations, not proof that the required tests have passed. Verify them in the same Hardware Simulator environment used by your course. If you substitute any built-in chip for a lab chip, disclose that in your report as the assignment requests.
